# Recipe Page

A responsive recipe page built with semantic HTML and CSS as part of a Frontend Mentor challenge.

## Overview

This project presents a complete omelette recipe with preparation time, ingredients, step-by-step instructions, and nutritional information.

The layout adapts smoothly between desktop and mobile screens while preserving readability and visual hierarchy.

- Semantic HTML structure
- Accessible nutrition table
- Locally hosted custom fonts
- Full-width mobile image
- Responsive card layout

## Built With

- HTML5
- CSS3
- Flexbox
- Media queries
- Custom fonts

## What I Learned

This project helped me improve my understanding of semantic HTML and responsive CSS. I practiced using ordered and unordered lists, accessible tables, local fonts, responsive widths, and media queries.
